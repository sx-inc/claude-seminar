# claude-seminar

Claude Code セミナー(2026-10-09)の配布物とスライドです。

## 実習で使う zip

次の URL から `claude-seminar.zip` をダウンロードして展開します。

https://github.com/sx-inc/claude-seminar/releases/latest/download/claude-seminar.zip

展開したあとの手順は、zip の中の `README.txt` に書いてあります。

## 入っているもの

| 場所 | 中身 |
|---|---|
| `claude-seminar/` | zip と同じ中身。Skill `research-deck` は `.claude/skills/research-deck/SKILL.md` にあります |
| `deck/project/` | スライド 31 枚。1 枚が 1 つの HTML ファイルで、並び順は `deck.json` にあります |
| `実行例/` | `/research-deck 日本の中小企業の事業承継の現状` を 4 回実行してできた .pptx |
