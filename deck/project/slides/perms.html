/permissions

よく使う安全なコマンドを先に許可し、
チームの設定ファイルに保存する

/sandbox

Claude が操作できる範囲を決める。
範囲内の操作は確認を省いて実行する

auto mode

バックグラウンドで安全性を検査しながら作業を進める

93% は auto mode の記事、84% はサンドボックスの記事に載っている Anthropic 社内の数字。「Claude Code power user tips」は、/permissions でよく使う安全なコマンドを先に許可する方法を勧めている。公式ドキュメントの表は、bypassPermissions を使う場所を「隔離したコンテナと VM だけ」としている。
