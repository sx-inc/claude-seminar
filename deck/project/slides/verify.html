出所: Claude Code power user tips(support.claude.com)/ Best practices(code.claude.com)

「Claude Code power user tips」は、この項目を「the #1 Tip」と呼んでいる。Best practices は、確かめる方法を渡すかどうかで、人が見ている必要があるセッションと、人が離れていられるセッションに分かれると書いている。コード以外の業務でも同じように渡せる。資料なら「この見本と見比べて」、数字なら「合計がこの値と合うか確かめて」と入力する。
