付録　Claude Code チームの使い方

覚えておくコマンド 8 つ

/btw

会話の履歴に残さずに質問する

/rewind

会話とコードを前の時点へ戻す

/context

コンテキストの使用量を表示する

/simplify

4 つのエージェントが、変更したコードを並列で見直して直す

/batch

大きな変更を 5〜30 個の作業に分け、並列で進める

/fewer-permission-prompts

過去の会話を調べ、許可するコマンドの一覧を作る

/insights

自分の使い方を分析したレポートを作る

/loop

決めた間隔で同じ指示を繰り返す

出所: Commands(code.claude.com)/ Claude Code power user tips(support.claude.com)

Bash が変更したファイルは、/rewind では戻らない。/simplify と /batch は、Skill として入っているコマンド。
