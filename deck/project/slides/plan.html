付録　Claude Code チームの使い方

実装の前に Claude に計画を作らせる

1

計画を作らせる

Shift+Tab で
plan mode に切り替える

2

計画を直す

Ctrl+G で計画を
エディタで開く

3

実装させる

実装が計画どおりか
Claude に確かめさせる

/clear

同じ問題を 2 回指摘しても直らなければ、会話を消して新しい指示で始め直す

出所: Best practices / Permission modes(code.claude.com)

plan mode では、Claude は先に計画を出す。計画が出たら、Ctrl+G を押して自分のエディタで直せる。下の帯は Best practices にある目安。指摘を重ねた会話には失敗したやり方の記録が残るので、会話を消して、分かったことを入れた指示で始め直すほうが早い。間違いを直したあとに「Update your CLAUDE.md so you don't make that mistake again.」と入力すると、Claude は CLAUDE.md に行を足す。
