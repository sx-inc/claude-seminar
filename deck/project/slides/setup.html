zip: github.com/sx-inc/claude-seminar の Releases　出所: Skills、Permission modes(code.claude.com/docs/en)

[0:05] この部は 10 分。claude-seminar.zip は、github.com/sx-inc/claude-seminar の Releases からダウンロードする。直接の URL は https://github.com/sx-inc/claude-seminar/releases/latest/download/claude-seminar.zip 。zip には、作業用のフォルダが入っている。Skill は、フォルダの中の .claude/skills/research-deck/SKILL.md にある。Claude Code は、起動したフォルダの .claude/skills を読むので、Mac、Windows、WSL のどれでも手順は同じになる。各自が zip を展開し、README.txt があるフォルダで claude を起動する。ターミナルでフォルダを開く方法は、下の表と README.txt に書いてある。Windows の「すべて展開」を使うと、claude-seminar フォルダの中にもう 1 つ claude-seminar フォルダができる。起動するのは、README.txt があるほうのフォルダ。WSL を使う人も、zip は Windows のエクスプローラーで展開する。Windows 側のフォルダにあれば、できあがった .pptx を PowerPoint で開ける。初めて起動するフォルダでは、フォルダを信頼するかを選ぶ画面が出る。最初に選ばれているのは No, exit なので、下向きの矢印キーで Yes, I trust this folder を選んでから Enter を押す。起動したら、画面の下に auto mode on と出ていることを確かめる。auto モードでは、権限の確認を Claude Code の分類器が代わりに判定する。Permission modes のページには、v2.1.283 以降は対話のセッションが auto モードで始まると書いてある。auto mode on と出ていない人は、Shift+Tab を押して auto mode on に切り替える。切り替えても出ない人は、claude を終了し、claude update で新しい版にしてから、claude --permission-mode auto と入力して起動し直す。同じページには、組織の管理者が auto モードを止められることも書いてある。その PC では auto モードを使えないので、権限の確認を読んで 1 件ずつ許可してもらう。次に / を入力し、一覧に research-deck があることを確かめる。一覧に出ない人がいたら、講師は、起動したフォルダに README.txt があるかを見る。講師の PC で 2026-10-08 に試したときは、README.txt があるフォルダで起動すると一覧に出て、1 つ上のフォルダで起動すると出なかった。pptx の Skill を入れる手順は任意で、入れていない PC でも research-deck は .pptx を作る。
