付録　Hook にする

Hook は決まった時点で必ず動く

SessionStart

会話を始めたとき、
再開したとき

UserPromptSubmit

利用者が指示を
送ったとき

PreToolUse

ツールを使う直前。
Hook は操作を止められる

PostToolUse

ツールを使った直後

Stop

Claude が応答を
終えるとき

Notification

Claude が入力を待っているとき

PreCompact

会話を要約する直前

Hook は、Claude の判断に関係なく Claude Code が実行する。

出所: Automate workflows with hooks(code.claude.com/docs/en/hooks-guide)。イベントは一部だけを載せた

Hook は、決まった時点で Claude Code が実行するコマンド。上の 5 つは、1 回のやり取りで起きる順に左から並べた。スライド 16 の例のうち 2 つが、橙色の時点を使う。公式ドキュメントは Hook を、LLM の選択に頼らずに特定の動作を必ず起こす仕組みと説明している。
