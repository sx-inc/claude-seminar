付録　使う機能を選ぶ

指示を書くと依頼になり、Hook は強制になる

CLAUDE.md・Skill に書く

依頼

「.env を編集しない」と書く。
Claude はこの指示を破ることがある。

Hook で止める

強制

Hook を設定する。
Hook は .env の編集を直前で必ず止める。

An instruction like "never edit .env" in CLAUDE.md or a skill is a request, not a guarantee. A PreToolUse hook that blocks the edit is enforcement.

出所: Extend Claude Code(code.claude.com/docs/en/features-overview)

下の英文は公式ドキュメントからの引用。CLAUDE.md や Skill に書いた指示は依頼で、保証にはならない。編集を止める PreToolUse の Hook は強制になる。どちらを使うかは、「この指示がたまに破られても困らないか」で決める。困る指示は Hook にする。
