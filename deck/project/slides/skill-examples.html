出所: github.com/anthropics/skills / github.com/anthropics/knowledge-work-plugins / github.com/nanaism/yomiyasu

上の段の 4 つは、Anthropic がファイル形式ごとに公開している Skill。review-contract と variance-analysis は、Anthropic の業務別プラグインに入っている Skill。yomiyasu はコミュニティが公開している Skill で、AI が書いた日本語を読みやすく直す。yomiyasu の description は、「この文章を読みやすくして」のような依頼の文を並べている。自分で Skill を作る前に、近い Skill を 1 つ開いて、description と手順の書き方を読む。
