付録　Skill にする

Claude に Skill を作らせて description を確かめる

1

Claude に頼む

「いまの手順を
Skill にして」と入力する

2

description を読む

使う場面と使わない場面が
書いてあるかを確かめる

3

新しい会話で試す

Skill の名前を入れずに
同じことを頼む

自分だけで使う

~/.claude/skills/<名前>/SKILL.md

チームで使う

.claude/skills/<名前>/SKILL.md

出所: Skills(code.claude.com/docs/en/skills)

実習 2 の待ち時間に、新しい Skill の作り方としてこのスライドを見せる。Claude に 1 回やらせたあとで「いまの手順を Skill にして」と入力すると、Claude は SKILL.md を書く。新しい会話で Claude が Skill を使わなかったら、「/名前」で呼び出し、description に使う場面が書かれているかを確かめる。下の 2 行は SKILL.md の保存先。
