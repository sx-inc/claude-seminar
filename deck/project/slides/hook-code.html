付録　Hook にする

Hook の設定は settings.json に書く

.claude/settings.json

{

  "hooks": {

    "PreToolUse": [

      {

        "matcher": "Edit|Write",

        "hooks": [{

          "type": "command",

          "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/protect-files.sh"

        }]

      }

    ]

  }

}

いつ動くか

PreToolUse は、ツールを
使う直前に動く

どのツールで動くか

matcher は、編集と
書き込みを指定している

何を実行するか

command のスクリプトが
exit 2 で終わると、
Claude Code は操作を止める

出所: Automate workflows with hooks(code.claude.com/docs/en/hooks-guide)

Claude に「.env を編集できないようにする Hook を設定して」と入力すると、Claude は .claude/settings.json にこの設定を書く。設定は、いつ動くか、どのツールで動くか、何を実行するかの 3 つを読む。公式ドキュメントのスクリプトは jq を使う。Hook は、やりたいことを伝えると Claude が書く。
