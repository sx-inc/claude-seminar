出所: How we built our multi-agent research system(anthropic.com/engineering)、配布した SKILL.md

[0:01] 今日やることは、テーマを Web で調べて PowerPoint の資料にするところまでを、各自の PC で Claude Code に任せること。入力するのは、/research-deck とテーマの 1 行。Claude Code は、配布した Skill の手順に沿って、テーマを 4 つの問いに分け、4 つのサブエージェントに同時に調べさせる。調査をしていない別のサブエージェントが、数値を出所のページと比べる。元のセッションが 8 枚の .pptx を作る。役割を分けた複数の Claude にタスクを進めさせることを、オーケストレーションと呼ぶ。調査を題材にした理由は、Anthropic の公式の事例にある。Anthropic は Research 機能で、リードエージェントが調査を複数のサブエージェントに分け、サブエージェントが並列に調べる構成を使っている。Anthropic の記事は、この構成が社内の評価で単一のエージェントより 90.2% 高い成績だったと書いている。同じ記事は、コーディングのタスクは調査に比べて並列にできる作業が少ないとも書いている。Agent teams の公式ドキュメントも、最初は調査とレビューから始めるよう勧めている。調べた結果を PowerPoint の資料にする部分は、このセミナー用に足した。実習は 2 回行う。1 回目は配布した Skill をそのまま実行し、2 回目は Skill を直して自分の業務のテーマで実行する。
