5　振り返り

公式ドキュメントに載っている Hook の例 4 つ

ファイルを守る

.env などの編集を止める

PreToolUse

コードを整形する

Claude が編集するたびに整形する

PostToolUse

決まりを読み直させる

要約のあとに決まりをもう一度渡す

SessionStart + compact

入力待ちを通知する

Claude が入力を待ち始めたら通知を出す

Notification

出所: Automate workflows with hooks(code.claude.com/docs/en/hooks-guide)

[1:18] 今日の実習のように実行に時間がかかるタスクには、右下の「入力待ちを通知する」Hook が使える。公式ドキュメントは、この 4 つの設定例を載せている。「決まりを読み直させる」の Hook は、Claude Code が長い会話を要約したあとに、決まりをもう一度 Claude に渡す。「入力待ちを通知する」の Hook を設定すると、利用者は通知が届くまで別の作業を進められる。
