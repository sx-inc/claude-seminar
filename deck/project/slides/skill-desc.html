付録　Skill にする

Skill を使うかどうかは description で決まる

Anthropic が公開している xlsx Skill の description(抜粋)

使う場面

Use this skill any time a spreadsheet file is the primary input or output.

使わない場面

Do NOT trigger when the primary deliverable is a Word document …

Claude は最初に
description だけを読む

使う場面と使わない場面を
両方書く

1,536 字を超えた分は
切り捨てられる

重要な条件を先頭に書く

出所: Skills(code.claude.com/docs/en/skills)/ github.com/anthropics/skills の xlsx

作った Skill が使われないときは、最初に description を見直す。Claude は最初に description だけを読み、Skill を使うと決めたあとで本文を読む。Anthropic が公開している xlsx の Skill は、使う場面と使わない場面を両方書いている。description と when_to_use は、合わせて 1,536 字を超えた分が切り捨てられる。
